## 使い方

- 各行の「操作 → 期待する結果」を行い、合っていれば `[ ]` を `[○]` にする。
- 合わなかったら、チェックを付けずに、その観点の「結果」に、起きたことを書く。直したら、直したことと日付を書き足す。
- 1 つの観点を通しで終えたら、「結果」に日付と「OK」（または直したことの一覧）を書く。

## 準備

- exe は `WebDeza/bin/Release/net10.0-windows/webDeza.exe`（`dotnet build CoverCropper.slnx -c Release` で作る）。設定（`%APPDATA%\webDeza\settings.json`）は書き換わってかまわない。
- 画像を 3 枚以上用意する: 横長の大きな画像（例 4000×3000）、縦長の画像、小さな画像（例 200×150）。
- 出力先には、テスト用の空のフォルダ（例 `D:\webDeza-test-out`）を作り、保存のダイアログの［変更…］で選んでおく。
- T01〜T06・T10〜T20 で使う画像は、Claude Code に作ってもらったフォルダ（12-2）を使う。中身は次の表のとおり（WebP・AVIF は作れないので、手元にあれば使う）。

| フォルダ | 中身 | 使う観点 |
|---|---|---|
| `formats` | `sample.jpg` / `.png` / `.bmp` / `.tif` / `.gif` / `.jxr` / `.heic`（1200×900）、`sample.ico`（256×256 と 32×32 入り）、`png_content.jpg`（中身が PNG）、`not_image.txt` | T03・T04 |
| `exif` | `portrait_orientation6.jpg`（EXIF の向きが 6。正しく回すと縦長 900×1200 で、文字「上（縦撮り）」と矢印が上を向く） | T05 |
| `transparent` | `transparent.png`（800×600。透明な背景に、不透明な赤い円・半透明の青い矩形・右へ透明になる緑の帯） | T06 |
| `many` | `img_1.jpg`〜`img_60.jpg`（640×480。番号入り） | T03 |
| `mixed` | `a.jpg`・`b.png`・`c.bmp`、非対応の `readme.txt`・`data.csv`、サブフォルダ `sub\d.jpg` | T03 |
| `noimages` | `readme.txt` だけ | T03 |
| `broken` | 中身が画像でない `broken1.jpg`・`broken2.png` と、正しい `ok.jpg` | T03 |
| `lock` | `lock_test.jpg` | T02 |
| `batch` | `photo_01.jpg`〜`photo_10.jpg`（4000×3000・約 6 MB） | T16・T17 |
| `large` | `large_8000x6000.jpg`（約 18 MB） | T18 |

- ファイルが変わっていないこと（T01・T20）は、次の PowerShell で、操作の前と後のハッシュと更新日時を比べて確かめる（Claude Code に「記録を取って」「比べて」と頼んでもよい）。

```powershell
function Snap($dir) { Get-ChildItem $dir -File -Recurse | ForEach-Object { "{0}  {1}  {2:o}" -f $_.FullName, (Get-FileHash $_.FullName).Hash, $_.LastWriteTimeUtc } }
Snap "<フォルダ>" > $env:TEMP\before.txt   # 操作の前
Snap "<フォルダ>" > $env:TEMP\after.txt    # 操作の後
Compare-Object (Get-Content $env:TEMP\before.txt) (Get-Content $env:TEMP\after.txt)   # 何も出なければ同じ
```
- Windows の表示スケールは 100% にしておく（T09 を除く）。
- 見た目は、明るいモードと暗いモード（設定 → 個人用設定 → 色 → アプリ モード）の両方で見る。モードを切り替えたら webDeza を起動し直す。

## T01 元画像の保護

時期: 12-2 の通し。`batch` フォルダをコピーして使う（以下「元のフォルダ」）。

**記録を取る**

- [○] 元のフォルダで、準備の `Snap` を実行して `before.txt` を作る

**元画像に触れる操作をひととおり行う**

- [○] 元のフォルダの画像を 3 枚開き、それぞれに、ぼかしの適用・切り抜き・回転をする
- [○] 1 枚ずつ保存する（`Ctrl+E`）。続けて、すべて保存（`Ctrl+Shift+E`）する
- [○] 保存のダイアログの［変更…］で、出力先を**元のフォルダ**にして保存する → 新しい名前（`元の名前_yyyyMMdd_HHmmss.jpg`）で保存され、元の画像は上書きされない
- [○] 編集したまま閉じる（M16 で［はい］）・すべて閉じる・終了する

**比べる**

- [○] `after.txt` を作って `Compare-Object` → 元の画像の行に差が無い（差は、元のフォルダに新しく保存したファイルの行（`=>`）だけ）
- [○] 終わったら、出力先をテスト用のフォルダに戻す

結果: 2026-11-18 OK（Claude Code が UI Automation で操作して確かめた）

- [○] すべて閉じてから、`mixed` の中の 5 ファイル（画像 3 つと非対応 2 つ）を選んで落とす → 同じ 3 枚が開く。ステータスバーに「3 件を開きました。非対応 2 件を除きました。」
- [○] `noimages` フォルダを落とす → ステータスバーに「フォルダに対応する画像がありませんでした。」
- [○] 「開く」で種類を「すべてのファイル」にして、`not_image.txt` を開く → エラー「対応していないファイル形式です。」（M01）

**読めないファイル**

- [○] `broken\broken1.jpg` だけを開く → エラー「対応していないファイル形式です。」（M01）。子ウィンドウはできない
- [○] `broken` フォルダを落とす → `ok.jpg` だけが開き、1 回のダイアログで「2 件を開けませんでした。」と、ファイル名と理由が 1 行ずつ出る（M29）

**上限（50 枚）**

- [○] すべて閉じてから、`many` フォルダを落とす → `img_1`〜`img_50` が開き（名前の数の順。`img_10` は `img_9` の後）、`img_50` がアクティブ。ステータスバーに「50 件を開きました。 同時に開けるのは 50 枚までです。10 件は開きませんでした。」
- [○] そのまま、ほかの画像を 1 枚落とす → 開かず、「同時に開けるのは 50 枚までです。1 件は開きませんでした。」
- [○] メニュー［ウィンドウ］ → 50 枚の一覧が出て、選ぶと切り替わる
- [○] ［すべて閉じる］ → すべて閉じる

**コマンドライン引数**

- [○] webDeza を閉じてから、PowerShell で `& "<exe のパス>" "<formats のパス>\sample.jpg" "<mixed のパス>"` → `sample.jpg` と `mixed` の 3 枚が開く
- [○] webDeza が起動しているときに、同じコマンドを実行する → 新しい webDeza が起動して開く（1 つにまとめる仕組みは無い）

## T07 選択範囲と切り抜き

時期: 段階 11 の前（10-12 で見直した画面で）。画像を 1 枚開き、道具は「選択」（`M`）にしておく。

**作る**

- [○] キャンバスをドラッグ → 始めた点と今の点を対角にする矩形ができ、縁が白と黒の点線で出る。編集パネルの X・Y・幅・高さと、ステータスバーの「選択範囲: (X, Y) 幅×高さ」が追いかけて変わる
- [○] 画像の外までドラッグ → 選択範囲は画像の端で止まる
- [○] もう一度別の所をドラッグ → 前の選択範囲が置き換わる

**移動**

- [○] 選択範囲の内側にカーソルを置く → カーソルが移動の形になる。ドラッグすると動き、大きさは変わらない。画像の外へは出ない
- [○] 矢印キー → 1 px、`Shift`+矢印 → 10 px 動く。画像の端で止まる

**ハンドル**

- [○] 比率「自由」 → 四隅と四辺にハンドルが出る。ドラッグすると、反対側の角（辺）を固定して大きさが変わる
- [○] 反対側を越えるまでドラッグ → 裏返らず、1 px で止まる
- [○] 比率「4:3」 → ハンドルは四隅だけ。ドラッグしても 4:3 が保たれる（幅と高さの入力欄で確かめる）
- [○] 道具を「手のひら」（`H`）にする → 選択範囲の縁は出たまま、ハンドルは消える

**数値の入力**

- [○] X・Y・幅・高さに値を入れて `Enter` → 選択範囲が変わる。画像からはみ出す値は、内側に収まる
- [○] 値を入れて `Tab`（フォーカスを外す） → 当てはまる。値を入れて `Esc` → 元の値に戻る
- [○] 全角の数字（例 `１００`） → 受け付ける。数字でない値 → 元の値に戻る
- [○] 比率が決まっているとき、幅を入れる → 高さが比率から決まる（高さを入れると幅が決まる）
- [○] 選択範囲が無いとき → 入力欄は空欄で、入力できない

**すべて選択・解除**

- [○] 比率「自由」で `Ctrl+A` → 画像全体が選ばれる
- [○] 比率「16:9」で `Ctrl+A` → 16:9 でいちばん大きい矩形が中央に置かれる
- [○] `Ctrl+D` → 解除される
- [○] 選択範囲の外を、ドラッグせずにクリック → 解除される
- [○] 編集パネルの［すべて選択］［解除］ → `Ctrl+A`・`Ctrl+D` と同じ

**比率**

- [○] 自由 / 元画像と同じ / 1:1 / 4:3 / 3:2 / 16:9 を順に選ぶ → 今の選択範囲が、中心と面積をなるべく保って新しい比率になる。画像からはみ出さない
- [○] 比率を何回か変えてから、最初の比率に戻す → 変え始める前の選択範囲から合わせ直すので、位置と大きさのずれが積み重ならない
- [○] 4:3 で［縦横を入れ替え］ → 3:4 になり、選択欄の文字も 3:4 になる。そのまま 16:9 を選ぶ → 9:16 になる
- [○] 自由・元画像と同じ・1:1 → ［縦横を入れ替え］が無効
- [○] カスタムで 1200:630 を入れる → その比率になる。［縦横を入れ替え］ → 630:1200 になる
- [○] 画像を 2 枚開いて比率を変える → 両方の画像の選択範囲が新しい比率になる
- [○] 比率を 3:2 にして終了し、起動し直す → 3:2 のまま

**切り抜き**

- [○] 選択範囲を作って `Ctrl+Shift+X` → 画像が選択範囲の大きさになり（ステータスバーの「画像: 幅×高さ」）、選択範囲が解除され、全体表示に戻る
- [○] メニュー［画像］→［選択範囲で切り抜き］、編集パネルの［切り抜き］ → `Ctrl+Shift+X` と同じ
- [○] 選択範囲が無いとき → 3 つとも無効
- [○] `Ctrl+Z` → 切り抜く前に戻る。`Ctrl+Y` → もう一度切り抜いた状態になる
- [○] 切り抜いた画像を保存（`Ctrl+E`）して、ほかのビューアーで開く → 選んだ範囲どおりの中身と大きさになっている

結果: 2026-11-18 OK（利用者が exe で確かめた）

## T08 ズーム・パン

時期: 段階 11 の前（10-12 で見直した画面で）。大きな画像と小さな画像を開いておく。

**ズーム**

- [○] マウスホイール → カーソルの下の点を中心に拡大・縮小する（カーソルの下の点が動かない）。ステータスバーの倍率が変わる
- [○] `Ctrl++` / `Ctrl+-`、メニュー［表示］→［表示拡大］［表示縮小］、ツールバーのボタン → 表示の中央を中心に拡大・縮小する。1 回で 1.25 倍
- [○] 拡大を続ける → 3200% で止まる。縮小を続ける → 全体表示の倍率と 10% の小さい方で止まる
- [○] `Ctrl+0` / ［全体表示］ → 画像全体が収まる。小さな画像（200×150）では 100% を超えない
- [○] `Ctrl+1` / ［100%］ → 100% になる
- [○] 大きく拡大する → 画素の境目がくっきり見える（ぼやけない）。縮小しているときは、なめらかに見える

**パン**

- [○] 「手のひら」（`H`）でドラッグ → 表示が動く
- [○] 中ボタンでドラッグ（道具は「選択」のまま） → 表示が動く。選択範囲は変わらない
- [○] `Space` を押しながらドラッグ（道具は「選択」のまま） → 表示が動き、カーソルは移動の形になる。`Space` を離すと、選択の操作に戻る
- [○] 画像が表示の領域より小さい向き → その向きには動かず、中央のまま
- [○] 画像が表示の領域より大きい向き → 画像の端が、領域の内側まで入り込まない所で止まる

**大きさが変わったとき**

- [○] 全体表示のまま子ウィンドウの大きさを変える → 全体表示し直す
- [○] 拡大してから子ウィンドウの大きさを変える → 倍率と、表示の中心が保たれる
- [○] 拡大してから 90° 回転・切り抜き・画像サイズの変更 → 全体表示に戻る
- [○] 2 枚の画像で別々の倍率にして切り替える → それぞれの倍率と位置が保たれる

結果: 2026-11-18 OK（利用者が exe で確かめた）

## T09 高 DPI

時期: 12-2 の通し（Q7）。表示スケールを 150% と 200% にして、それぞれで行う。

**準備**

- 設定 → システム → ディスプレイ →「拡大/縮小」を 150% にする（サインインし直すよう言われたら従う）。webDeza を起動し直す。
- 1 px 幅の縞模様か格子の画像を用意する（無ければ Claude Code に作ってもらう）。

**確かめること**

- [○] 縞模様の画像を 100%（`Ctrl+1`）で表示し、画面のスクリーンショット（`Win+Shift+S`）を等倍で見る → 縞が 1 物理ピクセルずつで、つぶれたり、にじんだりしていない
